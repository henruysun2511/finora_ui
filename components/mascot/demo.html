Cách Sử Dụng Components Trong Toàn Bộ Ứng Dụng

Mỗi mascot là một file component riêng biệt trong thư mục device-preview/components/mascot/. Bạn có thể chèn trực tiếp dưới dạng thẻ HTML Web Component hoặc gọi qua JavaScript API.

<!-- 1. Nhúng base engine và component mascot bạn cần --> <script src="../../components/mascot/base.js"></script> <script src="../../components/mascot/nora.js"></script> <!-- 2. Hiển thị dạng Avatar nổi với Speech Bubble --> <mascot-nora size="140px" float interactive bubble="Hôm nay bạn chi tiêu rất tốt!"></mascot-nora> <!-- 3. Hiển thị dạng Card chọn nhân vật --> <mascot-nora mode="card" active></mascot-nora> <!-- 4. Hiển thị dạng Dialogue Chat Row --> <mascot-nora mode="dialogue" bubble="Bạn vừa tiết kiệm được 50k!"></mascot-nora> <!-- 5. Hoặc gọi bằng JavaScript thuần --> <script> // Lấy mascot theo số dư tài khoản: const mascot = window.FinoraMascots.getMascotByBalance(12500000); document.getElementById("myContainer").innerHTML = mascot.renderCard({ active: true }); </script>
